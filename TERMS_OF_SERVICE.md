## 2. Description of Service

ThePatrick is a free-to-use, source-available community bot that provides:

- AI-powered chat responses via Cloudflare Workers AI
- AI image generation and image analysis
- Escape from Tarkov game data lookups (prices, ammo, maps, traders)
- Counter-Strike 2 player stats and a case opening simulator with a server leaderboard
- Random meme fetching
- Discord slash commands and Twitch chat commands
- Tarkov roleplay allergy tracking
- An admin-managed roleplay hate list with AI-generated roasts
- Durable server-wide AI memory based on Bot interactions
- A local web dashboard for server administrators
